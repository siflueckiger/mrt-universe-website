# AGENTS.md

Single-page p5.js web game ("Magic Ramba Trash"). No framework, no build step, no package.json, no tests or lint. Classic `<script>` tags in global scope (early-www style) — works from `file://` or any static server; do not convert to ES modules without asking.

## Structure

- `index.html` — markup only, plus p5 + p5.sound CDN tags (with SRI hashes) in `<head>` and script tags in load order at end of `<body>`. Includes the `#chaos-hud` (big centered CAT CHAOS MODE readout) that replaces the explorer HUD in chaos mode.
- `css/style.css` — all styling, incl. the CRT/scanline overlay (`#crt-overlay`), the red `#chaos-overlay` glimmer and the `#chaos-hud` + `hud-glitch-out` animation.
- `js/config.js` — `GAME_CONFIG`: all tunables (world bounds, `activationDistance`, movement speed/acceleration, `warp`, `catMode`, joystick, entity counts incl. nebulae/asteroids/trash, star/link/planet/nebula/asteroid/particles/trash ranges, link min spacing, minimap, sound, distance unit/scale, CRT overlay). `mobileBreakpoint` must stay in sync with the `@media (max-width: 768px)` rule in `css/style.css`.
- `js/links-data.js` — `linkData` array + `validateLinkData()` (warns and drops malformed entries at load; normalizes missing `description`). Adding a link = editing this array only.
- `js/classes.js` — `Star`, `Ship` (UFO, or the 1.5× cat head in cat mode via `displayCat()`, optional `assets/` image via `loadCatImage()`), `Link`, `Navigator`, `Planet`, `Nebula` (drifting gas clouds, `blendMode(SCREEN)`), `Asteroid` (tumbling rocks), `ThrusterParticle` (retro exhaust), `Trash` (collectibles; optional `assets/trash/` PNG/GIF sprites via `loadTrashImages()`, procedural pixel-art fallback), `ExplosionShard` + `Shockwave` (cat-mode blasts, collected in the `explosions` array), plus per-destruction flavors `SupernovaFlash` (stars), `GasBurst` (nebulae) and `TextShard` (a destroyed link's title letters).
- `js/ui.js` — info/how-to-play overlay (`infoMenuOpen`, `toggleInfoMenu()`, I key / HUD button, ESC/backdrop closes, pauses the game) + HUD DOM code (incl. `formatDistance()` for the lightyear display, HTML escaping, change-only DOM writes and the cached `mobileQuery`) + the Cat Chaos HUD (`updateChaosOverlay()` body class + `--chaos-level`, `updateChaosHud()` targets/auto-fire readout) + the link list overlay (`linksListOpen`, `toggleLinksList()`, L key / HUD button, arrow keys or W/S move the cursor, ENTER picks, I jumps to info, picks pin any link as navigation target) + the Warp HUD button (`initWarpButton()`, `updateWarpButton()`, mirrors the J key for touch) + the in-game video preview modal (`previewOpen`, `openPreview(link)`, `closePreview()`, `openPreviewLinkInTab()`, `initPreviewModal()`, `getYouTubeId()`; V key near a link, `youtube-nocookie` iframe, ENTER opens the link in a new tab, non-embeddable links get an "open in new tab" fallback, closing clears the iframe `src` so audio stops).
- `js/controls.js` — `joystick` input state + action button (opens links, or fires in cat mode); exposes `window.updateActionButton` for the draw loop.
- `js/sound.js` — chiptune blips via p5.sound oscillators (`playSound(name)`, no audio files) incl. `warp`/`warpEnd`/`pickup`/`laser`/`explosion`/`chaos`/`roar`/`star`/`planet`/`nebula`/`linkPop` sweeps + looping UFO hum while moving (`setFlying(on)`, driven by `handleInput`) and the escalating cat-chaos "wrath" drone (`setChaosDrone(level)`, driven by `chaosProgress()`, stopped by `stopChaosDrone()`); audio unlocks on first key/tap, `M` / the HUD Music button toggles mute (`initSoundButton()`), `GAME_CONFIG.sound.enabled` disables audio entirely.
- `js/game.js` — `gameState` (single source of truth: `appReady`, `nearestLink`, `selectedLinkIndex`, `accelerationFactor`, `warpActive`, `catMode`, `laserTarget`/`laserFrames`/`screenShakeFrames`), p5 hooks (`setup`, `draw`, `keyPressed`, `windowResized`), input/game logic, warp/autopilot (`startWarp()`, `endWarp(silent)`, `updateWarp()`, screen-space `warpStreaks`), the floating `[ENTER] Open` / `[V] Preview` prompt above the UFO (`drawShipPrompt()`), trash collection (`trash` array, `trashCollected`, `collectTrash()`), Cat Chaos mode (`setCatMode()`/`toggleCatMode()`, `getNearestOnScreenTarget()`, `fireCatLaser()`, `destroyTarget()`, `createExplosion()`, `drawLaser()`, `chaosRemaining()`/`chaosProgress()`, escalating red-glimmer `#chaos-overlay` + endless ambient screen shake), rapid fire/auto-fire (`F`, `igniteCascade()`/`nudgeNearby()`, frantic cat movement via `catMode.moveSpeedMultiplier`/`thrusterMultiplier`), the void end state (`updateVoid()`, `drawVoidCat()`, `rebirthUniverse()`) and `spawnWorld()` (rebuilds the cosmos for setup + rebirth), visited links (session-only Set), mini-map, and the boot guard.

## Script load order (critical)

p5 CDN → p5.sound CDN → `config` → `links-data` → `classes` → `ui` → `controls` → `sound` → `game`. Earlier files define globals used by later ones; `game.js` calls `initInfoMenu()`/`initLinksList()`/`initWarpButton()`/`initPreviewModal()`/`initSoundButton()` and defines p5 hooks last.

## Running & verification

- Any static server works, e.g. `python3 -m http.server`; opening `index.html` directly also works. p5.js 1.4.0 + p5.sound load from cdnjs, so previews need network; if p5 fails, `game.js` shows a fallback error in the HUD instead of a blank screen.
- Syntax check all JS: `for f in js/*.js; do node --check "$f"; done`
- No automated tests; testing is manual in the browser. Checklist: arrow/WASD/joystick movement, ESC deselects, a floating `[ENTER] Open` / `[V] Preview` pill appears above the UFO within `activationDistance` (V only for YouTube links), ENTER/action button opens link within `activationDistance`, V previews a YouTube link in the CRT modal (ESC/V/X closes and stops audio, ENTER opens the link in a new tab; Flickr links show the new-tab fallback), J (or Warp button) engages autopilot to the pinned/nearest link and any key cancels it, mobile controls below 768px, resize re-centers ship, UFO hum while moving (stops when stopped), M toggles sound, mini-map top-right shows links/ship (unvisited links pulse yellow, visited are faint gray, legend below the box; hidden in Cat Chaos, where the explorer HUD glitches out and the centered `#chaos-hud` shows CAT CHAOS MODE + targets remaining + key hints), select/open/reach/pickup blips play after first key/tap, visited links show ✓ and reset on reload, L opens the link list (game pauses, arrow keys or W/S move the cursor, ENTER pins a row), I opens/closes the info overlay, nebula drift + asteroid tumble + thruster particles visible, trash pieces tumble and deplete the `Trash: X / total` HUD counter when flown into, collecting all trash awakens Cat Chaos (cat head, hold SPACE (or F auto-fire) rapid-laser destroying the nearest on-screen link/planet/asteroid, then nebulae/trash/stars, until "Nothing remains. Only the cat." then a giant cat fades over the void and `[R]` rebirths the cosmos), destroyed links burst into title letters, dead stars flash as supernovae, big kills trigger cascades + a shove shockwave + lingering wreckage, the red-glimmer `#chaos-overlay` pulses and the ambient shake grows as destructibles fall, a rising wrath drone + per-type destruction sounds play, CRT overlay visible.

## Conventions & gotchas

- UI copy is English (`lang="en"`); new text should follow surrounding language per element.
- The scripts are non-module global code — don't wrap in modules or strict scoping; p5 global mode finds `setup`/`draw`/`keyPressed`/`windowResized` on `window`.
- `gameState.appReady` gates all input and starts `true`: the game is playable immediately and the info/how-to-play overlay is opt-in via `I`.
- Links spawn via rejection sampling (`GAME_CONFIG.link.minDistance` between links, `minShipDistance` from the ship) so they never overlap; falls back to the most spaced candidate.
- Distances are displayed in the configured unit (`GAME_CONFIG.distance`: `unit` + `pixelsPerUnit`) via `formatDistance()`; the game still works in pixels internally.
- The link list pauses the game: `handleInput` returns early while `linksListOpen`, `infoMenuOpen` or `previewOpen`, and ESC inside the list is consumed by `ui.js` (stopImmediatePropagation) so it closes the list without deselecting.
- Mobile controls (`#mobile-controls`) are CSS-hidden above 768px, but joystick mouse handlers exist for desktop testing; keep both input paths in sync when changing controls.
- Movement is relative: the ship stays centered and the world (`stars`, `links`, `planets`, `nebulae`, `asteroids`, `trash`) moves via `moveObjects()`; `nebula.update()` adds slow independent drift.
- Visited links are tracked by `title` in a session-only `Set` (resets on every page load).
- Trash art is optional: drop PNG/GIFs into `assets/trash/` and list the filenames in `GAME_CONFIG.trash.items`; if the list is empty or an asset 404s, each piece falls back to procedural pixel art. Trash progress is session-only (resets on reload).
- Cat Chaos triggers when all trash is collected; for testing use `?chaos=1` (or `?cat=1`) in the URL, press `C` to toggle it, or `?void=1` to jump to the empty-cosmos end state. Press `R` on the void to rebirth the cosmos (rebuilds the world via `spawnWorld()`). Set `GAME_CONFIG.catMode.image` to an `assets/` filename to override the procedural cat head. `GAME_CONFIG.catMode.autoFire` seeds the runtime `gameState.autoFire` (toggled with `F`).
- The pixel-identical trashy early-www look is deliberate; refactors must not change visuals or HUD copy (the CRT overlay is a config-gated addition, `GAME_CONFIG.visual.crtOverlay`).
