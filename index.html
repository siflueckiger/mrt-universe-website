Welcome to the Magic Ramba Trash Universe

HOW TO PLAY:

  • Use the ARROW KEYS, WASD or the JOYSTICK to navigate and discover links.
  • ENTER or the ACTION BUTTON opens links when you're close to one.
  • L or the LINKS BUTTON opens the link list to pin any destination.
  • J or the WARP BUTTON engages the autopilot hyperdrive to your pinned link. Any key cancels it.
  • I or the INFO BUTTON shows this help screen at any time.
